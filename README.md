# 🪑 Rest & Relax Chairs — Chair Shop Website

A simple, fully responsive website for a fictional chair shop, built with **HTML** and **CSS** to practise layout and responsive design.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

**🔗 Live demo:** [prasad-chair-shop.netlify.app](https://prasad-chair-shop.netlify.app)

---

## ✨ Features

- **Sections:** hero, "What makes our chairs special", customer testimonial, bestselling chairs and footer
- **Fully responsive** — adapts to large screens, laptops, tablets and phones with CSS media queries
- **SVG icons** that stay sharp at any size
- Clean, well-structured HTML and CSS that's easy to read and learn from

---

## 🛠️ Tech Stack

- **HTML5** — structure
- **CSS3** — styling, Flexbox, Grid and media queries
- **SVG icons** — scalable graphics

---

## 🚀 Getting Started

No installation needed.

```bash
git clone https://github.com/prasad-k-s/Chair-shop.git
cd Chair-shop
```

Then open `index.html` in your browser.
